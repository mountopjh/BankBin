# BankBin - 银行卡 BIN 码查询与智能识别工具

BankBin 是一款专用于查询银行卡 BIN 码及其归属机构（发卡银行、卡片名称、卡种、卡号长度）的 Windows 桌面便携工具。支持本地极速离线识别与自动兜底查询。

---

### 📥 快速下载使用

本仓库为国内镜像分发通道，专供单文件绿色版程序直接下载：

1. 在上方文件列表中，点击下载最新版本的 `BankBin_*.exe`（推荐下载最新序号版本，如 `BankBin_014.exe`）。
2. 下载后直接双击即可运行，**无需安装任何运行环境或依赖**，纯净绿色免安装。
3. 首次启动后会在 Windows 任务栏右下角（系统托盘）显示 BankBin 图标。

---

### ✨ 核心功能特性

- **一键快捷查询**：
  - 划词智能识别：支持在表格、文档或网页窗口中选中银行卡号后自动弹出识别浮窗。
  - 快捷键监听：支持热键随时切换监听状态与快速查卡。
- **本地离线优先**：
  - 内置本地离线卡表数据库，毫秒级响应，断网环境下亦可秒级识别主流卡种。
- **查询大盘面板**：
  - 提供完整独立的操作面板与历史数据大盘，支持一键清空或重新检索历史卡号。
- **智能更新提醒**：
  - 系统托盘内置更新通道，支持一键检查版本更新与卡表自动同步。
- **安全与隐私**：
  - 查询历史与用户偏好保存在本地计算机（`%APPDATA%\BankBin`），不上传个人隐私数据。

### ⌨️ 常用操作说明

| 功能项 | 默认按键 / 路径 | 说明 |
| :--- | :--- | :--- |
| **监听开关** | `F6` | 开启/暂停剪贴板与划词自动监听 |
| **打开主面板** | 双击托盘图标 或 托盘菜单「打开主面板」 | 打开大盘统计与手动输入查询窗口 |
| **历史记录** | 托盘菜单「历史记录」 | 快速查看最近查询的 20 条卡号 |
| **退出软件** | 托盘菜单「退出程序」 | 完全安全退出后台常驻进程 |
